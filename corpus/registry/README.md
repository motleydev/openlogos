# corpus/registry

Metadata and rights records for every upstream source: commit or SHA-256 pin, SPDX license,
attribution, non-commercial and share-alike flags, declared versification and normalization mode
(specs/19-search-and-retrieval.md, Pipelines). No large or copyrighted dumps are ever committed
here. The registry format follows `schemas/rights-record.schema.json`; no records exist yet.
