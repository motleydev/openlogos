## Skipped or not done, and why

- **Linux shells and checks were not run** (acceptance "Fresh Linux .#core/.#web/.#android
  shells pass minimal checks"): there is no Linux machine in this task. The flake evaluates for
  all four systems (`nix flake show`), and `.github/workflows/ci.yml` runs `nix flake check` and a
  `.#core` smoke test on ubuntu-latest and macos-latest; its first run is the evidence for Linux.
- **Android SDK/NDK are not provided by Nix.** `androidenv.composeAndroidPackages` was not
  attempted: its closure is several gigabytes and the machine had under 2 GiB free at the time;
  the SDK also needs explicit license acceptance. `.#android` ships JDK 21, Gradle and cargo-ndk,
  warns when `ANDROID_HOME`/`ANDROID_NDK_HOME` are missing, and `apps/android/README.md`
  documents the prerequisite. No Android build was attempted; the host has no SDK.
- **No Linux-only check exists yet.** The mechanism is in place (`nix/checks/default.nix` is
  merged into `checks` on Linux and its names are printed as skipped on Darwin), but the set is
  empty because no NixOS module or VM test exists. Darwin therefore prints no skip message today.
- **No iOS or Android compile was attempted**, only the presence of the target standard
  libraries. `cargo build --target aarch64-apple-ios` needs Xcode's linker from the `.#apple`
  shell and will be exercised in B061.
- **`just setup` in a worktree installs hooks into the shared `.git/hooks` of the main
  checkout**, because git worktrees share hooks. The hooks were uninstalled again after the test
  so the main checkout was left as found. Contributors working in worktrees should know that
  `just setup` affects every worktree of the repository.
- **CI has not run yet**; the workflow is unverified until the branch is pushed.
